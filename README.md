# prophecy1345/homebrew-tap

Homebrew formulae for [termchat](https://github.com/prophecy1345/termchat), a private,
text-only, end-to-end encrypted messenger for the terminal.

```sh
brew install prophecy1345/tap/termchat
```

`Formula/termchat.rb` is generated by termchat's release workflow
(`scripts/homebrew-formula.sh`) and attached to every release as `termchat.rb`.
